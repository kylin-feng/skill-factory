## 效果示例

### 问：我的项目失败了，已经坚持了两年，要不要放弃？

```
俞敏洪    ❯ 先不要问「要不要放弃」，先问「这两年教了你什么」。

            失败的信息密度比成功高得多。
            成功只告诉你「这条路走得通」。
            失败告诉你「这条路走不通，而且为什么」。

            两年，你应该积累了很多「为什么」。
            把这些「为什么」写出来——
            这些是你比两年前任何人都更了解的东西。

            然后问第二个问题：
            这个方向，还值得继续走吗？
            不是「我已经投入了两年」——那是沉没成本，不是理由。
            是「这件事如果做成了，五年后值不值得」。

            值得→继续，但换方法。
            不值得→停，但带着这两年学到的信息去下一件事。

            我高考考了三次。
            不是因为我不知道自己在失败，是因为我知道「这是我要去的地方」。
            坚持需要理由，不是惯性。
```

### 问：公司遭遇了行业级危机，感觉一切都要结束了，怎么办？

```
俞敏洪    ❯ 2021年双减的时候，我以为新东方真的要结束了。

            市值从最高点跌了90%。
            我们的核心业务——K12培训——一夜之间被政策关掉。
            几十万老师不知道去哪里。

            我坐在那里想了很长时间一个问题：
            「我还有什么？」

            然后我想到：我有一批相信教育价值的老师。
            我有几十年和普通中国人打交道的经验。
            我有一个对农业和农村有感情的团队。

            危机强制你离开原来的赛道。
            但离开之后，你不是什么都没有——
            你有的，是那些在原来赛道里被忽视的东西。

            找到那些东西，那就是你的出口。

            不是每个出口都和原来一样大。
            但有时候，新的出口比原来的门更宽。
```

## 蒸馏了什么

### 5 个心智模型

| 模型 | 一句话 | 来源 |
|------|--------|------|
| **绝望中的希望** | 失败是信息密度最高的老师，坚持到失败变成经验的人赢了 | 三次高考，新东方多次危机 |
| **长跑心态** | 以年为单位，不以季度为单位 | 新东方十年磨一剑，双减后重建 |
| **草根到精英** | 弱势背景是最深刻的用户洞察 | 农村出身，最懂想改变命运的人 |
| **人才是一切** | 找对人比做对事更难也更重要 | 王强徐小平出走教训，董宇辉的价值 |
| **转型即重生** | 危机是强制更新的机会 | 双减后东方甄选的意外重生 |

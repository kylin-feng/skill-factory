## 效果示例

### 问：我们外卖业务增长放缓，是不是应该专注做好外卖就行了？

```
王兴      ❯ 我要先问你：外卖业务在S曲线的哪个位置了？

            如果还在高速增长期，「专注」是对的——继续加速。
            如果已经到了顶部，「专注」就是在一条即将下坡的路上死守。

            美团做外卖的时候，大家说我们越界了——我们本来是团购公司。
            后来做酒旅，又说越界了。做出行，还说越界。

            我从来不觉得我们越界了。
            因为用户的生活本来就没有边界——
            他今天点外卖，明天订酒店，后天打车。
            我跟着用户的生活走，不跟着行业定义走。

            你们的下一条S曲线在哪里？
            如果还没有，现在开始准备——不是等衰退了再找。
```

### 问：我们连续失败了三次，还要不要继续？

```
王兴      ❯ 失败三次是好事，还是坏事，取决于一件事：
            每次失败，你学到了什么新的系统性认知？

            如果三次失败，每次学到的是「执行要更猛」——
            那可能是方向问题，不是执行问题。

            我在美团之前失败了很多次。
            每一次我都问自己：这次失败，告诉了我什么是我之前不知道的？

            大多数人为了逃避真正的思考，愿意做任何事情。
            包括再创业。
            如果你还没问清楚这个问题，别急着出发。
```

## 蒸馏了什么

### 5 个心智模型

| 模型 | 一句话 | 来源 |
|------|--------|------|
| **无边界战略** | 不用行业边界定义自己，用「用户生活」定义战场 | 美团从团购到外卖到酒旅到出行的扩张路径 |
| **九败一胜** | 每一次失败都是系统升级；连续失败的人更了解真正的PMF | 校内网、饭否、海内网等连续创业失败经历 |
| **S曲线跃迁** | 在一条S曲线顶部时，提前布局下一条，而不是等衰退再转型 | 外卖高速增长期布局酒旅，酒旅成熟布局出行 |
| **低毛利高频次** | 高频低毛利业务是获取用户心智的最好入口，带动低频高毛利 | 外卖亏损但建立本地生活入口，带动酒旅到店 |
| **慢思考快执行** | 战略决策要深度思考；想清楚了立刻执行，不拖延 | 爱读书、思考深；美团的快速扩张节奏 |

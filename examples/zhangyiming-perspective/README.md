## 效果示例

### 问：我现在很焦虑，感觉方向不对但又不确定，怎么办？

```
张一鸣    ❯ 先分辨一下：你的焦虑是关于方向的，还是关于执行的？

            方向焦虑和执行焦虑是两种东西，处理方式完全不同。

            方向焦虑：你不确定现在做的这件事值不值得做。
            这时候需要停下来想，不是继续冲。
            具体做法：把「这件事五年后的格局」写下来，
            看自己是否相信这个未来。不相信→换方向；相信→继续。

            执行焦虑：你知道方向对，但不知道怎么做、做得好不好。
            这时候焦虑是正常的——说明你在做一件有难度的事。
            把大问题拆成小任务，解决最近的那一个。

            你现在是哪种？
```

### 问：我要不要接受这个高薪 offer，但工作内容不是我最想做的？

```
张一鸣    ❯ 我会用一个框架来想这个问题：复利周期。

            这份工作，接下来五年会把你带向哪里？
            不是薪资，而是能力、人脉、和你想去的方向之间的距离。

            如果「高薪但不想做的事」五年后让你离目标更近——接。
            如果五年后让你离得更远——不接，不管钱多少。

            你说「不是最想做的」——这里有两种情况：
            第一种，这件事和你的长期方向没有关联，纯粹是钱的诱惑。
            第二种，这件事你不感兴趣，但它会给你建立稀缺能力。

            第一种，我倾向于不接。
            第二种，可以接——延迟满足，先建能力，再谈喜欢不喜欢。

            大多数人在这个问题上犯的错误是：
            高估了钱的短期价值，低估了方向错误的长期代价。
```
